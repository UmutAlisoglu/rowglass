LOCAL BY DESIGN

Your tables stay yours.

Rowglass processes files in this tab. It makes no upload, analytics, or account requests and saves no input, filename, or comparison history. Clear everything or close the page to release the session.

The online page is hosted on GitHub Pages, which receives ordinary connection information when loading the app. Download the portable version to use it without a network connection. Saved reports and downloads stay where you save them.

Formats, limits & a few practical notes

CSV, TSV, and delimited text only. Export XLSX sheets to CSV first. Comma, tab, semicolon, and pipe separators are supported. UTF-8 and BOM-marked UTF-16 files are accepted. Each table needs a header row with unique, non-empty names and a consistent number of cells.

Up to 10 MB, 20,000 data rows, 200 columns and 1,000,000 cells per table. Blank physical lines are skipped; quoted blank values remain data. Header spaces are trimmed; header names are otherwise case-sensitive. Choose a different separator if detection is wrong.

Numeric comparison is optional, uses ordinary decimal/scientific notation and an absolute tolerance, and does not interpret currencies, date formats or decimal commas. Large numbers outside JavaScript’s safe integer range compare as exact text. This is a comparison of exported values, not formulas, formatting or workbook structure.

Matching columns should be stable identifiers. If an identifier itself changes, Rowglass shows a removed row and an added row. It does not guess whether they represent the same person or item. A report contains the values you imported, including any personal data.
